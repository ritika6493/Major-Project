# 🌍 Wanderlust
A full-stack travel listing web application where users can explore listings, create and manage their own listings, add reviews, upload images, and view locations on an interactive map.

# 🚀 Live Demo
https://major-project-thia.onrender.com/listings

# ✨ Features
- User Signup & Login
- User Authentication & Authorization
- Create, Edit & Delete Listings
- Add, Edit & Delete Reviews
- Image Uploads using Cloudinary
- Interactive Maps using Mapbox
- Session Management

# 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- EJS
- Cloudinary
- Mapbox
